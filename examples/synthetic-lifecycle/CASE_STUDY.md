# Synthetic case study: a refused launch followed by accepted local work

Synthetic local demonstration; no independent user or customer validation is claimed. This case describes the historical sample run.

The question was whether an installed Compound binary could preserve one inspectable unit of work across a refused launch and a later accepted command. A synthetic text artifact provided a result whose bytes could be checked independently of the subprocess exit code.

The run created and claimed one work item. An unsupported harness was then requested. Compound refused before launch; the complete WorkEnvelope and RunAttempt inventory matched their pre-request values. The same claimed work then ran a supported local command through the governed execution path. Exact artifact bytes and a successful forward-linked attempt were checked before closing the work as completed with audit_only. A final proof-chain doctor returned success.
