# measurement branch

Load for the actual measurement task. Use the [common execution contract](../README.md#common-execution-contract); this file grants no action authority.

## Trigger and input

A shipped change/cohort has an observation question or mature window.
Input: Instrumentation/data provenance, actual exposure, baseline/comparison, denominator and declared window.

## Procedure and composition

Check events are consumed by the real measurement owner, not merely emitted in tests. Report effect/uncertainty and guardrails; separate attribution from association. Account for missingness, immature cohorts and total cost. Compare declared criteria without moving the goalposts.
Optional complement: platform analytics/statistical methods only when the actual data requires them. Verify installation, provenance and its narrower contract before loading. Do not import an external body merely because this branch names it.

## Output and proof

A decision-ready result: keep, change, stop or inconclusive, with limits and real data lineage.
Next context: strategy/experiment for the next decision; learning for a reusable failure or method delta. Record source/entity revision, falsifier, uncertainty and named receiving owner; require actual acknowledgment/consumption before claiming handoff. See the [source catalog](../SOURCES.md) for conceptual credits, not efficacy evidence.

## Silence and recovery

No fabricated business outcomes or platform-specific sales data treated as a universal cohort engine.
Preserve versioned queries/data windows; repair data integrity at its owner before interpreting trends.
Duplicate/stale events, unavailable capacity/consumer, immature windows or a missing grant select no-op, bounded observation or explicit defer. A routing offer proves none of execution, recovery, operator-time savings or business impact.
